# 月坛初中与小区定位参考地图

本仓库是一个可直接通过 GitHub Pages 发布的静态参考地图，数据核验日期为 **2026-10-25**，对应 2026 年招生资料。地图和数据仅覆盖北京市西城区月坛片区，不是官方招生结论，也不提供个体入学资格判断。

## 数据范围与限制

- 初中招生名录包含的 10 所学校，不代表每个校址都位于月坛、某个小区独占对口某校，或保证录取；应以当年官方招生政策及个人系统资格核验为准。
- 住宅主表共 11 条，其中 10 条有定位；**R27 铁二区仍未取得可靠住宅中心或入口坐标，不落点**。不能用商铺、社区代表点或学校位置代替。
- 16 个社区代表点属于独立参考层，默认隐藏；小学门牌与社区登记证据仍有缺口，现有部分证据不能推定每个门牌的入学资格。
- 地图默认聚焦月坛本地。片区外 M01、M09 仅在单独且默认关闭的参考层中；M05、M07 及其他初中实际校址未核实项不作为地图定位点。
- 学校实力分档是低置信度的历史参考，同档并列，不是官方排名，也不是 2026 年实测评价。

地图内保留了数据来源和限制说明。OpenStreetMap 地理数据的署名及版权信息见地图 attribution 和 [OpenStreetMap copyright](https://www.openstreetmap.org/copyright)；内嵌 Leaflet 的许可见 [`leaflet-LICENSE`](leaflet-LICENSE)。

## 更新与发布

更新静态站点时，审查并替换根目录的 `index.html`，确认页面使用的数据、日期、待核事项和来源说明一致，且没有链接到未发布文件或本机路径。页面为自包含 HTML，当前无需构建或安装依赖。将变更推送到 `main` 后，GitHub Pages 从仓库根目录发布。
